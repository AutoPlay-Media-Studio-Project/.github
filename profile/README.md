Menu pages should live on media you keep, in one named project. Loose pages wait off the live desk.

## How AutoPlay Media Studio Sits

AutoPlay Media Studio does not replace the media files you already keep. It sits beside that folder as a named disc menu for an AutoPlay Media Studio menu project you own.

If two people share a PC, each keeps an AutoPlay Media Studio media desk of their own. Extra pages wait for their own title instead of crowding the live autorun session.

A first visit should be one short menu page, then the same AutoPlay Media Studio disc menu the next day. That is enough to see if the layout holds on media you keep.

The board stays small on purpose. A local AutoPlay Media Studio profile is enough for everyday work on discs you own.

## Traffic Light

| Signal | On the AutoPlay Media Studio media desk | What you do |
|--------|-----------------------------------------|-------------|

| Amber | Pages from two discs mixed | Split the set before a large change |

## Open Order

1. Open the last AutoPlay Media Studio session on media you keep, not a new empty menu.
2. Read the disc menu, the page list, and the last handoff.
3. Finish one visible page inside AutoPlay Media Studio menu project.
4. Write what changed on media you own, then close with fewer loose pages than you found.
5. If the media desk feels crowded, drop anything that belongs to a different AutoPlay Media Studio job.

## After a Week

A week in AutoPlay Media Studio is not more live pages. It is the same disc menu, a shorter page list, and a note that still makes sense on Monday. If every page is live, nothing stands out.

Take finished pages off the live set so the next visit starts on the AutoPlay Media Studio menu project that is still open.

Other programs stay where they are. AutoPlay Media Studio only keeps the path back: project name, disc menu, media desk, handoff.

## Field Note

AutoPlay Media Studio is easier to trust when the media desk stays smaller than the folder of loose pages around it. Name the project, keep the disc menu on media you own, finish one visible page, and write what changed.

The same loop fits a shop disc, a client packet, or a shared computer. Open the last AutoPlay Media Studio autorun session and continue. Do not rebuild the menu from scratch. Work only on discs and media you keep.
